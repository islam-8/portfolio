About Me

Islam Emad is an Electronics & Communications Engineer specializing in bare-metal systems, real-time digital signal processing, edge AI, and hardware-in-the-loop countermeasures. About →

I am an Electronics & Communications Engineer and embedded software designer driven by an endless curiosity for building and optimizing complex hardware-software systems. My engineering background spans bare-metal microcontroller development (AVR register-level architectures), real-time signal processing pipelines (FFT, ADPCM, adaptive NLMS filtering), and cutting-edge Edge AI integrations (quantized YOLO networks running deterministically under SCHED_FIFO Linux policies).

My graduation capstone project at Horus University—developing an advanced autonomous drone defense, tracking, and countermeasure hardware-in-the-loop system—achieved an A+ grade and was awarded 5th Place for Best Poster at the 43rd National Radio Science Conference (NRSC 2026). I am passionate about exploring the absolute processing limits of edge-level hardware and eliminating timing jitter in high-frequency applications.

Let's connect if you are passionate about embedded engineering, low-latency architectures, or deep industrial-scale hardware design!

My Projects

Awarded 5th Place (NRSC 2026)

Horus University Capstone

An autonomous defense countermeasure system tracking rogue drones via camera feeds. Runs NCNN quantized INT8 YOLOv8-nano on RPi 5. Uses Kalman filters (SORT) and isolates CPU cores using SCHED_FIFO real-time Linux scheduler to achieve sub-2ms predictability, triggering RF frequency sweeps based on real-time spectral analysis.

Raspberry Pi 5, YOLOv8-nano, NCNN, INT8, Kalman Filter, SCHED_FIFO

VoxLink Audio Mesh

Full-Duplex Serverless Audio

Real-time, multi-node voice communication over ESP8266 Wi-Fi using UDP broadcast. Extracts INMP441 mic frames via I2S DMA to ring buffers, runs a custom IMA ADPCM encoder (4:1 compression to 32kbps), and plays back audio on MAX98357A. Features static memory allocation inside the hot path to avoid heap fragmentation.

ESP8266, IMA ADPCM, I2S DMA, Ring Buffers, UDP Broadcast, LwIP Stack

Dual-Axis Tracking System

Real-Time Solar Alignment Loop

Tracks the sun on horizontal and vertical axes using 4 LDRs behind a quadrant divider. Built on ATmega32A in bare-metal C with a 20ms control loop. Samples channels with 10-bit ADC, conditions noise, uses Timer1 Fast-PWM for servo steps, and prevents hardware jitter through a separate power rail topology and bulk capacitors.

ATmega32A, Bare-metal C, 10-bit ADC, Timer1 Fast-PWM, Port Registers

PTT-Free Audio Pipeline

Full-Duplex ESP-NOW DSP Node

Full-duplex speech communication over ESP-NOW. Implements a dual-stage on-device DSP pipeline: FFT-based spectral subtraction for static environmental noise, and a 32-tap NLMS adaptive filter to suppress narrowband interference. Features a lock-free triple-buffer scheme to eliminate playback glitches.

ESP32, ESP-NOW, NLMS Adaptive Filter, FFT Spectral Subtraction, µ-law, I2S DMA

Obstacle Avoidance System

Register-level C++ Control Loop

A smart rover triggering ultrasonic sensors in a round-robin cycle. Reads echo pulse durations using Timer1 input-capture hardware directly. Relies on port-bit writes to bypass Arduino's overhead, dropping decision-to-act cycles below 5ms while preventing H-bridge shoot-through failures.

ATmega328P, Timer1 Input Capture, H-Bridge Driver, Port Manipulation, Bare-Metal C++

mmWave Doppler Radar

Micro-Breathing Presence Detector

Detects human presence, speed, and angle using 24 GHz Doppler radar, tracing breathing micro-motions to identify completely stationary people. Decodes 256000-baud UART radar streams on Arduino Uno R4, implements a Hamming-window filter with speed thresholds, and draws a real-time polar grid in Processing.

RD-03D Radar Module, UART (256000 Baud), Arduino Uno R4, Hamming Window, Processing UI

Autonomous Threat Scanner

Structured Schema AI Reporter

An automated reconnaissance and vulnerability scanning pipeline coordinating Nmap, OWASP ZAP, Bandit, and Semgrep through a Python asyncio architecture utilizing Redis Streams. Feeds alerts to Gemini using few-shot CoT prompting to enforce JSON CVSS/CWE mappings, exporting PDF reports via ReportLab.

Python asyncio, OWASP ZAP, Nmap, Redis Streams, Gemini API, Docker, ReportLab

Manual Heap Allocator

Double Singly-Linked Data Structures

A console-based Patient and Appointment scheduling system featuring role-based read/write access controls. Coded strictly in C99 with manual memory management (malloc/free), nested linear singly-linked list structures, and custom multi-pass deallocation sweeps to prevent memory leaks.

C99, Manual Memory Allocation (malloc/free), Singly-Linked Lists, Linear Substring Searches

HC-05 Bluetooth Controller

USART Interrupt Relay Matrix

An ITI embedded systems capstone project driving 4 mains relays over Bluetooth. Integrates a USART receive interrupt on ATmega32 to parse single-byte control matrices, isolation and flyback protection via ULN2003, and race-condition prevention using interrupt-to-main-loop handshake synchronization flags.

ATmega32, USART Interrupts, HC-05 Bluetooth SPP, ULN2003 Darlington, Proteus VSM
